# NetEngine — 网络引擎

高性能网络引擎实现，提供自定义传输层能力。

## 特性

- **自定义传输层**：支持替换标准 `net/http` 传输层
- **高性能 HTTP 服务端**：基于自定义网络栈的高并发处理
- **协议扩展**：支持自定义协议编解码

## 模块依赖

这是一个内部实现模块，直接使用场景较少。核心功能由 Astra 主框架封装。

## 使用场景

通常通过 `astra.New()` 间接配置，无需直接导入：

```go
app := astra.New(
    astra.WithEngine(netengine.New(...)),
)
```
